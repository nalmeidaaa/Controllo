# 📐 Espaçamento

<img src="./assets/Exemplo espaçamento.png" width="300">

## 📏 Escala de espaçamento

- 4px → micro espaçamento
- 8px → textos e labels
- 16px → padrão entre elementos
- 24px → padding dos cards
- 32px → separação de seções
- 48px → grandes áreas de respiro

## 📌 Regra

Utilizar múltiplos de 8 para manter consistência visual.
